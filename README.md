# 🛠️ Multifaceted Data & Productivity Manager

A desktop productivity dashboard built with **Python**, **Tkinter**, and **SQLite** designed to unify task management, note-taking, event scheduling, and file management into a single interface.

---

## ✨ Features

- 📝 **Notes Manager:** Create, edit, and organize persistent notes backed by SQLite.
- 📋 **Interactive To-Do List:** Track pending and completed tasks with timestamp logging.
- 📅 **Calendar & Event Planner:** Schedule and manage deadlines using an interactive calendar picker (`tkcalendar`).
- 📁 **File & Document Organizer:** Attach, preview, and reference local documents directly within the workspace.
- 💾 **SQLite Persistence:** All user data, tasks, notes, and events persist locally in a `multitask_manager.db` database.
- ⏱️ **Real-Time Clock:** Live header clock for time management.

---

## 🏗️ Tech Stack

- **GUI Framework:** Python Tkinter / ttk
- **Database:** SQLite3
- **Dependencies:** `tkcalendar`
- **Language:** Python 3.x

---

## 🚀 Getting Started

### Prerequisites

Install required Python dependencies:

```bash
pip install tkcalendar
```

> **Note for macOS users:** If Tkinter is not installed by default with Python, install via Homebrew:
> ```bash
> brew install python-tk
> ```

### Running the Application

Clone the repository and launch the application:

```bash
git clone https://github.com/murshidkazi15/Multifaceted-Data-Manager.git
cd Multifaceted-Data-Manager
python "Multitasking Manager.py"
```
